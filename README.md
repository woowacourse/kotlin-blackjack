# kotlin-blackjack

- [x] 사용자는 게임에 참여할 인원들의 이름을 입력한다.
- [x] 사용자는 각 참여자가 카드를 받을지 받지 않을지 입력한다.
- [x] 참여자들의 이름과 나누어진 카드의 개수를 출력한다.
- [x] 참여자가 보유한 카드의 목록을 출력한다.
- [x] 참여자의 결과를 출력한다.
- [x] 카드는 문양과 등급을 가진다.
- [x] 플레이어는 이름과 사용할 카드를 가진다.
- [x] 플레잉 카드의 등급을 만든다.
- [x] 플레잉 카드의 문양을 만든다.
- [x] 카드들에서 카드를 뽑는다.
- [x] 플레이어가 카드를 받는다.
- [x] 딜러는 이름과 사용할 카드를 가진다.
- [x] 딜러가 카드를 받는다.
- [x] 플레이어는 총 점수를 반환한다.
- [x] 딜러는 총 점수를 반환한다.
- [x] 각 플레이어의 승패를 반환한다.
- [x] 딜러의 승패들을 반환한다.
- [x] 오류 발생시에 재입력 기능 구현
- [ ] 배팅 금액은 마이너스가 되지 않는다.
- [ ] 배팅 금액은 판정 결과에 따라 금액을 계산한다.

## 1차 피드백 사항
- [ ] Flow에 앞서 게임이 가지는 여러가지 요소들에 대한 기본 역할들을 명확히 정의해보는 연습
- [x] 도메인 포함되어 있는 역할중에 UI의 역할에 어울리는 기능 이전
- [x] 협력과 자율성의 측면을 생각해보고, 객체 역할 분리
- [x] Deck 카드의 자료구조 변경
- [x] inputView가 outputView에 의존을 가져야 하는지 생각해보고 분리
- [x] open class, abstract class, interface의 차이점 학습 및 적용

## 2차 피드백 사항
- [x] InputView에 OutputView 상태 제거
- [x] draw와 카드가 부족할 경우 추가하는 기능 분리
- [x] Hands에 방어적 복사 활용
- [x] Player 생성 시점을 늦춰서 카드를 생성자 파라미터로 활용
- [x] 참가자가의 카드에 카드를 주기보다는 참가자가 카드를 받도록 변경
- [x] Verdict 객채를 만들어서 활용
- [x] 뽑는 카드 수 의존 이동
- [x] 의미 없는 ChoiceTest 제거
- [x] 테스트 코드 가독성 개선
- [x] 점수 테스트에서 Ace에 따른 조건을 좀 더 명확하게 기술
- [x] 참가자라는 역할에서 딜러와 플레이어가 다른 결과를 반환하도록 추상화
- [x] 참가자 생성에서 딜러는 생성자,참가자는 이름만 받는 부분 수정
- [x] 딜러가 히트를 받을지 여부를 판단하는 부분 달러로 이동
- [x] 컨트롤러에서 반복해서 출력하는 로직 View로 이전
- [x] DSL 빌더 생성 및 이름 예외처리


## 3차 피드백 사항
- [ ] DSL Builder에서 필수 요소 생성자 파라미터로 받아서 사용
- [ ] 컨트롤러에서 객체끼리 메시지를 던지는 비즈니스 로직 추출
- [ ] 비어있는 덱을 채우기 보다 새로운 덱을 만들어서 사용하도록 수정(테스트 포함)
- [ ] 게임 결과 반환은 게임중에 결과를 반환하도록 수정
- [ ] 추상화를 통해 카드를 받는 로직 관리
- [ ] list 타입 변환으로 Record 상태 수정 가능성 테스트
- [ ] 참가자끼리 대결을 공통 객체 함수로 추출
