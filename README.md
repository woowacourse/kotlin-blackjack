# kotlin-blackjack

## 기능 목록

### 입력 (`InputView`)
- [x] 참가자들의 이름을 입력받는다.
  - [x] 참가자들의 이름은 `,`으로 구분한다.
  - [x] 참가자의 이름은 공백으로만 이루어질 수 없다.
- [x] 각 참가자가 히트할지 스탠드할지 입력받는다.
- [x] 잘못된 값이 입력됐을 시 다시 입력받는다.

### 출력 (`OutputView`)
- [x] 참가자들의 이름과 처음에 주어진 카드의 개수를 출력한다.
- [x] 참가자가 보유한 카드의 목록을 출력한다.
- [x] 참가자의 결과를 출력한다.
- [x] 최종 승패를 출력한다.

### 카드 (`Card`)
- [x] 카드는 문양과 등급을 가진다.

### 덱 (`Deck`)
- [x] 덱은 52장의 카드가 든 덱을 생성한다.
- [x] 덱은 카드를 한 장 뽑아서 반환한다.

### 패 (`Hand`)
- [ ] 패는 카드들을 가진다.
- [x] 패에 든 카드들을 반환한다.
- [x] 패에 카드를 추가한다.
- [x] 패에 든 카드의 점수를 반환한다.
- [x] 패의 버스트 기준 충족 여부를 반환한다.

### 참가자 (`Participant`)
- [x] 참가자는 이름과 패를 가진다.
- [x] 참가자는 자신의 패를 공개한다.
- [x] 참가자는 카드를 받아 패에 추가한다.
- [x] 참가자는 자신의 패의 점수를 반환한다.
- [x] 참가자는 자신의 버스트 여부를 반환한다.

### 플레이어 (`Player`)
- [x] 플레이어는 참가자의 모든 기능을 가진다.
- [x] 플래이어는 패에 든 모든 카드를 공개한다.
- [x] 플레이어는 딜러를 상대로 승/패/무 상태를 반환한다.

### 딜러 (`Dealer`)
- [x] 딜러는 참가자의 모든 기능을 가진다.
- [x] 딜러는 패를 공개할 때 처음에는 한 장만, 그 후에는 모든 카드를 공개한다.
- [x] 딜러는 모든 플레이어들의 승/패/무 상태를 반환한다.
- [x] 딜러는 자신의 승/패/무 횟수를 반환한다.
