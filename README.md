# kotlin-blackjack


## 기능 구현 목록

### 카드
- [x] 숫자와 패턴을 가진 카드를 생성한다.
  - 1~10
  - 클로버/하트/다이아/스페이드

<br>

### 덱
- [x] 카드를 한 장 뽑는다.
- [x] 카드가 존재하지 않을 경우 카드를 뽑을 수 없다.

<br>

### 플레이어
- [x] 이름을 가지고 있다.
- [x] 카드를 받을 수 있다.
- [x] 가지고 있는 패의 총 합을 계산한다.
- [x] 받을 카드의 개수를 계산한다.
- [x] HIT 여부를 판단한다.

### 딜러
- [x] 카드를 받을 수 있다.
- [x] 덱에서 카드를 한 장 나눠줄 수 있다.
- [x] 가지고 있는 패의 총 합을 계산한다.
- [x] 받을 카드의 개수를 계산한다.
- [x] 패의 총 합이 16 이하인 경우 카드를 받는다.
- [x] 플레이어의 수익금을 계산한다.

<br>

### 패
- [x] 패에 카드를 추가할 수 있다.

<br>

### 점수 계산기
- [x] 패에 들고 있는 카드의 합을 구할 수 있다.

<br>

### 게임 결과
- [x] 게임 결과를 생성한다.

### 베팅 금액
- [x] 금액을 받는다.
- [x] 금액은 0보다 크다.

### 베팅 정보
- [x] 플레이어와 금액을 받는다.

### 수익금
- [x] 수익금을 받는다.
